# Structured Travel Data as the Portal Source

Syncing Travel raw route folders such as `路线/` and `路线_新/` are temporary intake areas, not frontend data sources. We use reviewed Structured Travel Data as the trusted route, destination, and media layer because raw documents and webpages can be duplicated, Chinese-only, incomplete, outdated, or mixed with non-publishable media. The portal may still keep internal source traces for maintenance, but traveler-facing pages must consume cleaned English route products and reviewed media manifests.
