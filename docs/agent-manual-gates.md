# Agent Manual Gates

本文件定义必须由用户手动确认的决策门禁。Agent 可以执行低风险细节，但不能替用户做方向性决定。

## 必须用户确认

| Gate | 说明 | 例子 |
|---|---|---|
| 产品方向变化 | 改变页面定位、导航结构、转化路径或业务流程 | 把 `China Trips` 改成普通 tours 页面 |
| 审美方向变化 | 改变整体视觉气质、品牌感或参考风格 | 从克制旅游门户改成强营销落地页 |
| 新依赖 / 新框架 / 新服务 | 引入长期维护成本或外部服务绑定 | 新状态管理库、新 UI 框架、支付服务 |
| 架构或长期维护成本变化 | 改变数据流、路由体系、组件边界或构建方式 | 重构 `siteData.ts` 为新数据层 |
| 内容事实来源不明确 | 缺少可靠来源但会影响公开内容 | 价格、团队成员、客户评价、路线事实 |
| 真实业务操作 | 会影响真实用户、外部系统或资金流 | 部署、发邮件、写数据库、支付、账号配置 |
| 跨 Agent 负责范围修改 | 修改未声明 owner 的文件或共享文件 | 页面 Agent 想改数据源或全局样式 |

## Agent 可自行处理

- 读取任务相关文件。
- 做最小范围代码或文档修改。
- 清理本次改动造成的 unused import、变量、函数。
- 运行不会修改源码的验证命令。
- 更新交接进度和任务板状态。
- 把已确认的重复规则沉淀到对应文档。

## 请求确认模板

```md
## Manual Gate Request

- Gate：
- 背景：
- 为什么需要用户确认：
- 可选方案：
- 推荐方案：
- 不确认时的默认处理：
```

## 判断原则

如果一个决定会影响用户看见的产品方向、长期维护成本、事实真实性、真实业务动作或其他 Agent 的负责范围，就先停下请求确认。
