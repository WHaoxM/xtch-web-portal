# Admin 表单样板：路线 + 目的地可懂化

日期：2026-07-17  
状态：已落地  
计划：`.cursor/plans/admin_表单样板中文化_c321bee9.plan.md`

## 问题

运营反映表单难懂：不知道改哪会影响前台哪块。侧栏已中文化；本任务把**路线 + 目的地**做成可复用样板。

## 决策

- **做**：列表与编辑 chrome 全中文；按前台影响面分区；易混字段加一句 `FieldHint`；枚举下拉中文显示、英文入库。
- **不做**：班期/素材/分类/定制表单；公网预览链；API/schema；i18n 框架。内容值（旅客文案）仍英文。

## 可复用模式

| 模式 | 用法 |
|------|------|
| `FormSection` | `border-t` + 中文 `h3` + 可选区说明 |
| `FieldHint` | 字段下 muted 一行用途说明 |
| `CONTENT_STATUS_LABELS` 等 | option 显示中文，`value` 仍英文 |
| `AdminEditShell.backLabel` | 样板模块传 `← 返回列表`；其他 Panel 默认英文 |

## 分区

**目的地：** 基本信息 → 首页与排序 → 分类 → 状态  

**路线：** 基本信息 → 卡片与筛选 → 详情页内容 → 逐日行程 → 价格与状态
